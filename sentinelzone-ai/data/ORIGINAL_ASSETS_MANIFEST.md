# Original SentinelZone-AI assets

This manifest records the original repository assets restored for the LinkedIn showcase scenarios and the existing demo pipeline. The current UI is not changed by these assets.

## Upstream source

- Repository: https://github.com/Free-devloper/SentinelZone-AI
- Reference: `origin/main`
- Commit: `bc8e2c88d376575503e77351f1b123b13c547535`
- The upstream repository stores MP4 and model binaries through Git LFS. Raw GitHub tree entries are pointer blobs; use Git LFS to restore binaries.

The machine-readable OID/size list is in `data/original_assets_manifest.json`.

Restoration is content-addressed by Git LFS. Do not replace a binary with its 128–134 byte pointer, and do not use `git checkout origin/main -- data` over the dirty worktree.

## Verification and restoration

Run verification without changing files:

```bash
python scripts/verify_original_assets.py
```

If a clean checkout has LFS pointers, explicitly fetch the media first:

```bash
python scripts/verify_original_assets.py --fetch-lfs
```

The fetch mode is limited to the original video paths and does not touch application source, UI files, or the current curated demo assets.

## Exclusions

This restoration does not relabel/augment data, retrain models, change the UI, or claim that the LinkedIn benchmark numbers have been reproduced.
